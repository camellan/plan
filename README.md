# ПСК «ИСКРА» — Расчёт плана

Десктопное приложение для автоматизации обработки и анализа производственных планов по автомобилям моделей **LJO**, **BJO** и **BJOC** из файлов Microsoft Excel.

## Основные возможности

* **Пакетная загрузка Excel-файлов (`.xlsx`, `.xls`, `.xlsm`)**:
  * Поддержка перетаскивания файлов в окно программы (Drag-and-Drop) и выбора через проводник.
  * Распознавание дат (`ДД.ММ.ГГГГ` или `ДД,ММ,ГГГГ`) в именах файлов, хронологическая сортировка и контроль пропусков дат.
* **Расчёт производственного плана на смену**:
  * Поиск стартового автомобиля по последним 5 цифрам **VIN**.
  * Подсчёт количества автомобилей **LJO**, **BJO** и **BJOC** 
  * Расчёт наиболее частой очерёдности (моды размера непрерывной пачки) для `LJO/BJO(C)`.
* **Работа в системном трее и автозапуск**:
  * Возможность сворачивать программу в системный трей при закрытии окна (с запоминанием выбора).
  * Опция **«Запускать вместе с Windows (в трей)»** в контекстном меню иконки трея (запуск с аргументом `--autostart` без показа основного окна).
* **Сохранение состояния и автономный кэш сессии**:
  * Автоматическое сохранение размеров окна, последней открытой папки, введённых значений **VIN** и **Плана**.
  * Кэширование загруженных таблиц в `%LOCALAPPDATA%\PSK_ISKRA\PlanAnalyzer\session_cache.pkl` — сессия и последний расчёт восстанавливаются при перезапуске даже в том случае, если исходные Excel-файлы были перемещены или удалены.

## Требования для запуска из исходного кода

* Python 3.10 или выше
* Установленные библиотеки:
  * `PyQt6`
  * `pandas`
  * `openpyxl` (для `.xlsx`, `.xlsm`)
  * `xlrd` (для старого формата `.xls`)

## Запуск из исходников

```bash
pip install PyQt6 pandas openpyxl xlrd
python plan.py
```

Для фонового запуска в системный трей без открытия окна:

```bash
python plan.py --autostart
```

## Сборка исполняемого файла (.exe)

Подробная инструкция по сборке приведена в файле [`build.txt`](build.txt). Быстрая команда сборки с использованием подготовленной конфигурации:

```bash
pyinstaller --clean plan.spec
```

Готовый файл `plan.exe` появится в папке `dist/`.
